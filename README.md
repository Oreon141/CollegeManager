## Технические характеристики программного обеспечения

### Вес программного обеспечения

Приложение разработано на платформе WPF (.NET Framework) с использованием SQL Server и Entity Framework.
Ориентировочный размер установленного приложения составляет:

* Клиентская часть: 80–150 МБ
* SQL Server Express: около 1–2 ГБ
* Дополнительные библиотеки и зависимости: до 300 МБ

Общий рекомендуемый объём на диске для стабильной работы системы — от 5 ГБ свободного пространства.

---

### Скорость установки

Среднее время установки программного обеспечения:

* Установка приложения: 2–5 минут
* Установка SQL Server Express: 5–15 минут
* Первичная настройка базы данных: 2–10 минут

Полное развёртывание системы обычно занимает от 10 до 30 минут в зависимости от производительности компьютера.

---

### Максимальный объём базы данных

Система рассчитана на хранение:

* пользователей,
* учебных курсов,
* модулей,
* заданий,
* сообщений,
* уведомлений,
* учебных ведомостей и файлов.

При использовании SQL Server Express максимальный размер одной базы данных составляет 10 ГБ.

Для образовательного учреждения этого достаточно примерно для:

* 5 000–20 000 пользователей,
* сотен тысяч сообщений,
* десятков тысяч заданий и учебных материалов.

При необходимости система может быть перенесена на полноценный SQL Server без ограничений SQL Express.

---

### Требования к компьютеру

Минимальные системные требования:

* Процессор: Intel Core i3 / AMD Ryzen 3
* Оперативная память: 4 ГБ
* Свободное место на диске: от 5 ГБ
* ОС: Windows 10 / Windows 11

Рекомендуемые требования:

* Процессор: Intel Core i5 / AMD Ryzen 5
* Оперативная память: 8 ГБ
* SSD-накопитель

---

### Стоимость компьютера

Для комфортной работы приложения подойдёт офисный компьютер стоимостью:

* Минимальная конфигурация: 30 000 – 45 000 ₽
* Рекомендуемая конфигурация: 50 000 – 80 000 ₽

Серверная часть может размещаться как на отдельном сервере, так и на обычном ПК администратора.

---

### Затраты на внедрение

Основные затраты на внедрение системы включают:

| Статья расходов          | Примерная стоимость |
| ------------------------ | ------------------- |
| Установка и настройка ПО | 5 000 – 15 000 ₽    |
| Настройка базы данных    | 5 000 – 10 000 ₽    |
| Обучение сотрудников     | 5 000 – 20 000 ₽    |
| Техническая поддержка    | по договорённости   |
| SQL Server Express       | бесплатно           |

При использовании бесплатной версии SQL Server Express дополнительных затрат на лицензирование базы данных не требуется.

Общие начальные затраты на внедрение системы составляют ориентировочно от 15 000 до 50 000 ₽ в зависимости от масштаба организации.
